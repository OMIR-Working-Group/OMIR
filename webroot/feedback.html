Spec feedback

Browse the OMIR R1 specification tree and attach feedback to any part — a whole section, or a specific resource at its maturity level. This is how the standard stays honest: maturity is a promise about change, and the fastest way to move a resource up the OMIR Maturity Model is real implementer feedback.

How this works. Feedback you save is stored locally in your browser (nothing is uploaded). When you're ready to file it with the Working Group, use Open as GitHub issue on any item — it pre-fills an issue against OMIR-Working-Group/OMIR with the section and maturity level attached. You can also export everything as JSON.
