The gap

Agents already talk. Their memory has had no shared shape.

Modern agents speak over MCP and A2A. But once memory leaves an agent and lands on disk, there has been no standard for what it should look like — so hand-offs stay fragile and migrations stay expensive.

01 · Portable

Memory as a Bundle

A Bundle of typed Resources can be exported, shared, archived, and consumed by any OMIR-compatible system.

02 · Small core

The useful 80%, no more

The spec captures the fields most implementations need, and leaves the rest to a clean extension mechanism.

03 · Honest memory

Decay & salience first-class

Fields for decay, tiering, relationship strength, and invalidation make forgetting a real part of the model.

04 · Evolution

A maturity model

OMM levels tell implementers which resources are stable and which are still moving — so you can trust what you build on.

Get started

From prototype to a standard-compliant export in days.

The schema is your fastest path. Use the JSON Schema as your contract, build your first .omir file as a Bundle, and link resources with typed references. Unknown extensions are safely ignored — innovate without breaking compatibility.
