Validate a Bundle to render its graph.

This in-browser validator implements the same R1 rules as the reference CLI — structural validity, required fields, UnitInterval ranges, additionalProperties:false, closed-world reference integrity, and the version marker. See Conformance for the full rule set and Guides to build your first Bundle.

Prefer the command line?

The reference validator (omir-validate, Apache-2.0) runs the same checks and emits a human or JSON conformance report.

# from the repository root
cd validator
cargo run -- ../examples/minimal-bundle.omir

#   structural ............. pass
#   reference integrity .... pass
#   version presence ....... pass
#
