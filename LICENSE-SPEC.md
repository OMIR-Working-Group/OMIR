## Required attribution

When you redistribute, adapt, or quote the OMIR specification or schemas, you
must include the following attribution string (or an equivalent that preserves
the same three elements — credit, license, and a link to the source):

> "OMIR — Open Memory Interoperability Resources" by the OMIR Working Group,
> licensed under CC-BY-4.0. Source: https://omir.io/ — modifications, if any,
> are indicated.

If you have modified the material, you must indicate that changes were made;
the trailing "modifications, if any, are indicated" clause is satisfied either
by stating the modification or, for verbatim copies, by leaving it as-is.

Group**. Veld convenes the Working Group but does not own the standard.
